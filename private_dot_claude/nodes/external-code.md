# External code

Before cloning any repo, installing any npm/pip/cargo package, or running anyone else's script:
**scan it first, and report what you found before proceeding.** If anything looks suspicious,
stop — do not clone and do not run it.

This overrides the default instinct to just fetch and run. It applies to code a tool or search
result surfaces exactly as much as to code Mike names by URL, and **popularity is not clearance**
— see `04_Resources/Tools/Siftly-Self-Hosted-X-Bookmark-Knowledge-Base-2026` in the vault for a
2.6K-star project that reads the Claude session out of the macOS keychain.
